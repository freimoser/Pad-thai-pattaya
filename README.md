# Pad Thai Pattaya – Top 10 Food Guide

Multilingual static site (DE / EN / TH) built with [Astro](https://astro.build) + Tailwind CSS.

## Live

https://Freemoser.github.io/pad-thai-pattaya/

## Develop

```bash
npm install
npm run build
```

Do not commit secrets. Deploy via GitHub Actions on push to `main`.

## Structure

- `src/data/` – restaurants & UI strings (de/en/th)
- `src/pages/[lang]/` – localized routes
- `public/` – robots.txt, favicon, OG image
